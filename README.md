# Webfolio — GitHub Pages Index

A simple landing page that links to five standalone website projects.

## Files
- `index.html` — homepage / index linking to every project
- `book-store.html` — online bookstore
- `cs-department.html` — Computer Science Department website
- `food-corner.html` — cafe / restaurant website
- `hospital.html` — healthcare website
- `university.html` — university website

## Publish with GitHub Pages
1. Create or open your GitHub repository.
2. Upload all six HTML files into the same folder (the repository root is easiest).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose your main branch and `/ (root)`, then save.
6. After deployment, open the published site URL. The `index.html` file is the landing page and each card opens its matching HTML file.

Note: This index links to the local files in the same repository, so keep the filenames unchanged unless you also update the links in `index.html`.
